# The Last Lamp on Bell Street

A complete English animated fable and a reusable Claude Code studio. Start with **output/The_Last_Lamp.mp4**. Play **audio/narration.wav** to hear the actor without the score. The project also includes the final mix, word timings, scene sources, caption sidecar and a per-reference analysis in **docs/Reference_Analysis.pdf**.

## Give Claude a topic

Extract the entire ZIP, open the **BellStreet** folder in Claude Code and enter the line below. The director creates a new episode folder so you can keep this demo.

```text
/make-fable A clockmaker who sells people five extra minutes
```

Claude Code recognizes project skills under .claude/skills. The six skills cover direction, reference analysis, scriptwriting, English performance, animation and sound/QC. Claude writes new visuals for a new story. Running the build command alone rebuilds the current authored story. If you use a text-only Claude chat, it needs a local coding environment to execute the renderer.

## Windows setup

Use 64-bit Python 3.12, Node.js LTS with npm, and FFmpeg with ffprobe on PATH. If needed, install the free prerequisites from python.org, nodejs.org and ffmpeg.org. Start PowerShell in the extracted BellStreet folder. The initial installation downloads ordinary Python and Node dependencies. The English voice weights and fonts are already included.

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
.\.venv\Scripts\python.exe studio.py build
```

On Linux or macOS, install the same prerequisites, then run:

```bash
bash setup.sh
.venv/bin/python studio.py build
```

Once dependencies are installed the production stages run locally. Generating voice, captions, animation, Foley, score and the MP4 uses no paid media service or API key. Claude Code access is managed separately by Anthropic. The demo can be played and rebuilt independently of Claude.

## Edit and rebuild

| Change | Files | Stages to run |
| --- | --- | --- |
| Script, pause or delivery | episode/script.json | build |
| Cast, gesture, staging or drawing | art/drawing.js and art/scenes.js | render, verify |
| Music, event sound or ducking | episode/sound.json and studio/mix.py | mix, render, verify |
| Output name or width | episode/film.json | render, verify |

Use the same environment Python and run `studio.py <stage>` for each stage. Valid render widths are 360 for a draft, 720 to match the references, and 1080 for a larger export. Every delivery uses 30 fps. For a still, run `python studio/render.py --poster 33` using that interpreter. To inspect motion with a scrubber, open **art/stage.html** after the first render. The browser preview uses the same artwork, though font rasterization may differ from the MP4.

For an independent edit create a new workspace with `python studio.py new my-fable`. Use the root virtual environment in the new folder. Run directories inherit Node packages from the root. Replace the script, scene actions, sound cues, title and file stem. The project reports a missing cue or a mismatched take if the story changes.

## Inside the demo

A brass counter measures each new flame on Mara’s route. The bakery lamp goes out, she relights it, and the counter clicks again. The story turns when a boy can hear the water under the bridge but cannot see where to step. A modern inbox briefly repeats the same mistake. The last image returns to the lamp.

The spoken-word track is generated by Kokoro INT8 with the male US English preset am_michael. Its word-group timing comes from the model’s own phoneme lengths. The performance changes speed and pauses by thought. The score is an original synthesized arrangement with event-timed Foley. The 2D artwork is drawn from code. See docs/Credits.md for software and asset provenance.

The complete production run and file validation were performed on Linux. Windows setup is provided for your local machine.
