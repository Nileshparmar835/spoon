# Read the reference package
Start with docs/Reference_Analysis.pdf. For new references, list every source, probe dimensions, fps, duration, audio channels and sample rate. Sample the opening, one repeated action, the first reversal, the human analogy and the end. Inspect another frame either side of any suspected cut. Take listening notes where playback is available. Identify whether a sound is observed, inferred or measured.

Make a table with one row per source. Record an approximate pivot time, what changes in the foreground, what stays fixed, word placement and how the author ends. Use a rough transcript only to locate events. Recheck names, numbers and technical labels. The reference's moral describes that clip and is not research for a factual claim.

Write three transferable rules and three elements to invent. For this collection retain the graphic heads, upper single-word caption, staged object lesson and selective warm light. Invent the protagonist, object, sequence of actions, music and closing line for each production.
