# Write what can be drawn
Write three candidate openings: an impossible-looking result, an interrupted task and an object in the wrong place. Choose the one a viewer could understand from a silent first frame. Explain the choice in one line.

Choose a motive, one measurable change, a repeated action and a person who bears its cost. Let the viewer predict the next repetition before you show its consequence. Move once into a modern parallel, then return to the original object for the ending. Prefer precise details such as the boy hearing the water below the bridge. Keep invented stories clearly fictional.

Write 180–260 words for a reference-length episode and adjust after the first read. Divide into connected thoughts in episode/script.json. Each row has a unique id, spoken, speed, pause in seconds, direction, and one optional accent word spelled as heard. Keep the directions outside spoken. Use punctuation to indicate intent. Read the question and the payoff aloud separately.
 
In docs/director.md list every id with the spoken cue, pose before it, event on it, pose after it and the actual timestamp once rendered. Change repeated shots when the meaning or stakes change. Cut a sentence if the corresponding picture already tells the viewer everything.
